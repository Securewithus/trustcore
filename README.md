# TrustCore

A real-time trust-scoring engine for payments, identity documents, and access events.
Built for IBM Z Datathon 2026. Track: Real-time AI for Critical Decisions.

Every event gets a 0-100 trust score, a flag (trusted, review, high-risk), and a plain-English reason.

## How it works

Two signals are combined in one pass:
- **Rules** catch known red flags (amount far above the user's norm, 1-4 AM activity, unfamiliar city, rapid bursts).
- **Isolation Forest** (scikit-learn) learns normal behavior and flags statistical outliers.

Score = 60% ML + 40% rules. Flags: 70 and above is trusted, 40 to 69 is review, below 40 is high-risk.

All data is synthetic, generated by the scripts in `data/`. Results on planted anomalies are a pipeline sanity check, not a real-world accuracy claim.

## Run it (Windows PowerShell)

```powershell
py -3.12 -m venv venv
venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt

cd data
python generate_data.py
python generate_identity_data.py
python generate_access_data.py

cd ..\model
python score.py             # payments
python score_identity.py    # identity documents
python score_access.py      # access events
```

Start the API and dashboard:

```powershell
cd backend
python app.py
```

Then open `dashboard/index.html` in a browser. The API runs at http://localhost:5000.

| Endpoint | Purpose |
|---|---|
| GET /api/summary | Counts by flag |
| GET /api/transactions?flag=high_risk&limit=20 | Scored transactions |
| POST /api/score | Score one new transaction in real time |

Note: on Windows with Smart App Control enabled, numpy or scipy files may be blocked. Python 3.12 or Google Colab are workarounds.

## IBM Z plan

TrustCore does not run on IBM Z yet. The planned path: train off-platform and deploy for inference through Machine Learning for z/OS, run the scoring API as a Linux workload on LinuxONE, and add a small neural scorer to use the Telum on-chip AI accelerator. Latency will be validated on IBM Z before any performance claim.
